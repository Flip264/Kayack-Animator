KAYACK ANIMATOR 0.6.7

Unzip the whole folder. Open index.html in a modern desktop browser.
For GitHub Pages, upload the folder contents including the new duel.js,
workspace.js and fix067.js. Refresh the page after deployment.

Start with New character, or Open an existing sprite, game, character ZIP,
or workspace ZIP. Your 0.6.6 saved workspace ZIP is supported.

Open adds characters. Workspace lists, reorders and removes them.
Save offers the current character or the whole workspace.
Export (For Game) creates the same sprite ZIP format as before.
Compact exports still use the included Kayack Motion 1.1 extension.

Select objects, click a player/weapon, then drag the visible arrows or ring.
Enable P2, select a workspace character, then use Play mode to control both.
P1: WASD, Q, 1-5. P2: arrows, U, I O P K L. Change bindings in Settings.

Settings > Language supports English and Korean.
Read CHANGES-0.6.7.txt for changes, clash behavior and P2 compatibility limits.
